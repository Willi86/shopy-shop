# Sitemap

Sitemapen visar vilka sidor som finns i e-handeln och hur användaren kan navigera mellan dem.

```text
/
├── Produkter
│   └── /products
│
├── Produktdetaljer
│   └── /products/:id
│
├── Varukorg
│   └── /cart
│
├── Checkout
│   └── /checkout
│
├── Login
│   └── /login
│
└── Admin
    ├── /admin
    ├── /admin/products
    ├── /admin/products/new
    ├── /admin/products/:id/edit
    └── /admin/orders
```

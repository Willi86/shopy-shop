# Projektplan

## Mål

Målet är att utveckla en fungerande e-handel där kunder kan se produkter, lägga produkter i en varukorg och skapa en order.

Administratörer ska kunna logga in, hantera produkter, se ordrar och ändra orderstatus.

Projektet utvecklas för att uppfylla kraven för betyget VG.

## Teknik

Projektet planeras använda:

- React
- TypeScript
- Vite
- Supabase
- PostgreSQL
- Supabase Auth
- Tailwind CSS
- React Router
- Git och GitHub
- Vercel
